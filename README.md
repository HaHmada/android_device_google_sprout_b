Mito A10 Impact
==============

Android One devices (codenamed _"sprout_b"_) are low-range smartphones from Google with Mito.

Android One was announced in Google I/O 2014.

Basic   | Spec Sheet
-------:|:-------------------------
CPU     | Cortex A7 Quad Core 1.3GHz MT6582
GPU     | Mali-400MP2
Memory  | 1GB RAM
Shipped Android Version | 6.0.1
Storage | 8GB
Battery | 1780 mAh
Display | 4.5" FWVGA IPS (480x854)
Camera  | 2MP + 5MP Auto Focus with Flash Light

![Android One](https://github.com/HaHmada/assets-repository/blob/main/sprout_b/mito-a10.png "Mito A10 Impact")

This branch is for building CyanogenMod 13 (or Marshmallow 6.0.1 AOSP based roms) ROMS.
